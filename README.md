# Cold Case Initiative 🕵️‍♂️📁

An interactive, cinematic forensic storytelling web application. Designed to simulate a secure police terminal where users investigate a series of digital case files.

### 🔗 Live Demo
**[Click here to view the live project](https://cold-case-initiative.vercel.app)**

###  Key Features
* **State Management:** Vanilla JavaScript logic for sequential file unlocking.
* **Modern UI/UX:** Custom dark-mode CSS featuring glassmorphism, 3D hover tilts, and terminal typewriter effects.
* **Immersive Audio:** Integrated Web Audio API for synthetic system sounds (no external mp3 files).
* **Responsive Design:** Optimized for desktop and mobile views.

###  Technologies Used
* HTML5
* CSS3
* Vanilla JavaScript
